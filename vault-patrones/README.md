# vault-patrones

Conocimiento reutilizable y ya confirmado sobre creacion de cuentas en Kondor K+/K+TP. Todo lo que vive aqui paso por aprobacion. Las propuestas sin confirmar van primero a `candidatos/`.

- `kondor/cuentas/` - estandar de campos, naturaleza contable, catalogos de valores permitidos.
- `candidatos/` - valores o reglas propuestas, pendientes de confirmar antes de promoverse al estandar.
